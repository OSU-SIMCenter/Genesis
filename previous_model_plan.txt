Thermal Physics Implementation Plan
Goal Description
Implement thermal physics (temperature) modeling in the Genesis MPM solver. The goal is to allow particles to carry temperature, transfer it to the grid, and receive updated temperature back, enabling thermal simulation. This will be implemented by creating a specialized 

MPMSolver that inherits from and extends 
BaseMPMSolver.User Review Required

class MPMSolver(BaseMPMSolver):
    def get_particle_state_template(self):
        # Extend base fields with 'temp'
        return super().get_particle_state_template() | {"temp": gs.ti_float}

    def get_grid_cell_state_template(self):
        # Add 'temp_m' (thermal momentum: mass * temp) to grid
        return super().get_grid_cell_state_template() | {"temp_m": gs.ti_float}

@ti.kernel
def g2p_thermal(self, f: ti.i32):
    for i_p, i_b in ti.ndrange(self._n_particles, self._B):
        if self.particles_ng[f, i_p, i_b].active:
            # ... standard MPM spline calculation ...
            
            # Read back from Grid
            grid_temp_m = self.grid[f, base + offset, i_b].temp_m
            grid_mass = self.grid[f, base + offset, i_b].mass
            
            # Compute grid temperature (Heat / Mass) safely
            grid_temp = grid_temp_m / ti.max(grid_mass, 1e-10)
            
            new_temp += weight * grid_temp
            
            # Update particle temperature
            self.particles[f + 1, i_p, i_b].temp = new_temp
Step 2c: Integrate into Stepping Loop
Override the simulation steps to call the new kernels alongside the base ones.
def substep_pre_coupling(self, f):
    # Run standard momentum P2G
    super().substep_pre_coupling(f)
    # Run our extra thermal P2G
    self.p2g_thermal(f)

def substep_post_coupling(self, f):
    # Run our thermal G2P
    self.g2p_thermal(f)
    # Run standard momentum G2P
    super().substep_post_coupling(f)
